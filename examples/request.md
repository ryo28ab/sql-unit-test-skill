# 依頼文テンプレート

```text
$design-sql-unit-tests

以下の資料から取得処理の単体テスト仕様書を作成してください。
対象：［オブジェクト名・種別］
仕様：［文章、添付名、または参照先］
実装：［貼り付け、添付名、または参照先］
DDLと依存定義：［貼り付け、添付名、または参照先］
案件ルール・ひな形・過去の指摘：［あれば指定］
単体の境界・データ初期化方法：［分かれば指定］
出力形式：［会話内の表など］

不足情報や矛盾があれば、必要な理由を添えて先に質問してください。
回答に依存するテストデータや期待結果は、回答後に設計してください。
```

資料を用意できない場合は、その旨を回答し、どの範囲を暫定設計するかを指定してください。
